# infrastructure/terraform

Módulos Terraform para a arquitetura alvo (ADLS Gen2, Azure Databricks workspace, Key Vault, RBAC). Status: `Demonstrated conceptually` (ADR-0002) — o Databricks Free Edition não expõe account console/API para provisionamento real via Terraform. Os módulos aqui documentam a intenção de IaC para quando o ambiente corporativo/Azure estiver disponível.
